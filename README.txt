Father's Day Tribute Static Website

How to use:
1. Open index.html in any browser.
2. The two uploaded photos are already included in assets/.
3. Optional: add your full-screen hero background video as assets/hero-background.mp4.
4. Optional: add your personal thank-you video as assets/personal-thank-you-video.mp4.
5. Upload the whole folder to Netlify, Vercel, GitHub Pages, cPanel, or any static hosting service.

Files:
- index.html
- styles.css
- script.js
- assets/family-hero-1.jpeg
- assets/family-hero-2.jpeg

Notes:
The site is responsive and includes floating hearts, glassmorphism cards, reveal-on-scroll animations, timeline cards, quote rotation, cinematic overlays, and video placeholders.
